連接私人研究畫板

已記住這台瀏覽器的 PIN Google 用戶端設定，不需要重新輸入 ID。點下方按鈕恢復授權並讀取私人研究資料。

如果 Google 每次都要求選帳號，可填入您用來存取研究試算表的 Gmail。PIN 會用它提示 Google 優先選取帳號，但仍可能需要確認。

首次設定／查看或更換 OAuth Client ID
  1. 在 Google Cloud 啟用 Google Sheets API。
  2. 完成 OAuth 同意畫面設定（測試階段將自己的 Google 帳號列為測試使用者），並在 Google Auth Platform／Clients 建立「網頁應用程式」OAuth Client ID。
  3. 在「已授權的 JavaScript 來源」加入 https://thedoorw.github.io（不加 /PIN/）。將 Client ID 貼在下方。

只儲存非機密的 OAuth Client ID 於此瀏覽器；Google 存取權杖僅暫存在頁面記憶體。授權會要求 Google 試算表讀寫權限，範圍不限這一份檔案；試算表本身仍維持受限制存取。

修改儲存格後點到其他位置，即自動寫回 Google Sheets；多行備註也可按 Ctrl+Enter 儲存。若同一欄位已被其他地方更新，PIN 將停止覆寫並提示重新讀取。雙方請盡量在各自的備註欄協作；此版本不提供完整的歷史版本或即時多人鎖定。
