# PIN 網頁名稱與 Favicon

公開版設定檔：`config/site.json`。網站提供右上角「設定」按鈕，支援名稱、Favicon 圖片 URL 或本機上傳（PNG/JPG/WebP/ICO，256 KB 內），立即預覽。

**GitHub Pages 是靜態網站。**「儲存本機預覽」保存在使用者自己瀏覽器的 `pin:site-appearance-preview:v1`，不會修改 GitHub，也不會影響其他訪客。

如要全站公開：使用「匯出公開設定檔」，下載 `site.json`，將它提交至本 Repo 的 `config/site.json`，等待 GitHub Pages 部署。亦可以請 ChatGPT 直接修改該 Repo 的設定檔。這兩個欄位都是公開的，不可放密碼或秘密權杖。

「還原公開版本」只清除自己的本機預覽覆蓋。變更 Favicon 後若瀏覽器仍顯示舊圖，可能需要強制重新載入／新開分頁。若選用第三方圖片，須有合法使用權。

**不在公開網站內保管 GitHub 存取權杖**；如未來要直接在前台發布所有訪客可見的設定，需另外設計身分授權。

## 操作優化（2026-10-11）

網站標題列右上角以 36×36px 的橫向三點「⋯」開啟設定面板；點面板外任意位置或按 Escape 可關閉。點面板內的欄位、上傳和按鈕不會因 click-away 而關閉。

## 00 頂部導覽列與獨立 LOGO（2026-10-20）

- PIN 新增 **48px 高**的 00 頂部導覽列；LOGO 文字／圖片從 G0 內容左基準線 L 起，右側沿用既有搜尋作品與 `⋯` 設定控制，搜尋功能仍是原有作品型錄搜尋，不假裝已具備文章全文搜尋。
- 01 網站標頭仍從 `L+16px` 開始；02 分類導覽與 03 照片牆／私人研究文件維持已驗收的 G0 外框。
- 網站外觀面板新增 `navLogoText`（預設 PIN）及 `navLogoUrl`（可空）兩個**與 siteName／faviconUrl 完全分離**的公開設定欄位。圖片存在時優先顯示圖片，圖片無法載入時回退至文字；可按「移除 LOGO 圖片，顯示文字」。
- LOGO 圖片可輸入 HTTPS URL 或上傳 PNG／JPG／WebP，256 KB 以內。文字支援最多 50 字，超出可用寬度時省略顯示而不影響其他模組。
- 仍使用原先的 `pin:site-appearance-preview:v1` 本機預覽／儲存與「匯出公開設定檔」→ `config/site.json` 發布流程；既有設定若無新欄位即回退預設值，避免破壞舊版設定。
