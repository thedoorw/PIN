# PIN 技術收藏：ATN、JSX、SCRIPT、WORKFLOW

這些類型都存在 **PIN Repo 的型錄**，並與 Recipe 同庫管理，而非放到 Browser-QA 才能收藏與發布。

1. 先到 [型錄索引](../catalog/entries.json) 以永久 PIN-ID 立案，記錄原始作品頁、縮圖、技術來源及版權/取得條件。
2. 研究階段可在 `library/` 按 ID 存自寫的技法分析、可調參數、視覺問題與個人創作衍生方法。
3. 不得未經授權將第三方 JSX/ATN/Script 原始檔與第三方圖片鏡像進 Public Repo。未確認授權者保留原始 URL。
4. 使用者選定的技術可以直接由 **PIN → INK** 試用／執行。只有 INK 主程式需工程維修或 Runtime 驗證才啟用 Browser-QA。
5. 新增技術不需另外維護一份重複的 JSON；網站始終使用 `catalog/entries.json`。

> 有成熟可執行的技法時，依 [Recipe 格式](../recipes/RECIPE_FORMAT_v0.1.md) 建立與 INK 共用的轉譯方案。
